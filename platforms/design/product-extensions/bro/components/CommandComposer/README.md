# CommandComposer

**Status / Կարգավիճակ:** Draft (D-027)  
**Owner / Պատասխանատու:** MenQ Owner

## Հայերեն

Բրոյի մշտական հրամանի դաշտ։

**Ինչ է տալիս օգտագործողը.** `onSubmit`, ըստ ցանկության `placeholder`, `hint`, `sendLabel`, `label`։

**Props**
- `onSubmit(text)` — Enter՝ ուղարկել, Shift+Enter՝ նոր տող

**Կանոններ**
- Glass մակերես, focus-ի ժամանակ `color-selected` օղակ։

_Աղբյուր՝ MenQ addition (Bro)։_

## English

Persistent Bro command input.

**The consumer provides:** `onSubmit`, optional `placeholder`, `hint`, `sendLabel`, `label`.

**Props**
- `onSubmit(text)` — Enter sends, Shift+Enter adds a line

**Rules**
- Glass surface with a `color-selected` focus ring.
