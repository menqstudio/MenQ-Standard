# Product Extensions / Արտադրանքի ընդլայնումներ

**Decision / Որոշում:** [`D-027`](../decisions/D-027-MENQ-BRAND-EXPRESSION-LAYER-V1.md)

## Հայերեն

Կոնկրետ արտադրանքի ինքնություն, workflow-ներ և կոմպոնենտներ, որոնք shared core-ի մաս չեն (D-025 product boundary)։ Ամեն ընդլայնում ունի իր README-ն, PROJECT_CONTEXT-ը և ASSET_RECORDS.json-ը և կախված է [`../brand-expression/`](../brand-expression/)-ից։

- [`bro/`](bro/) — Բրո՝ MenQ AI գործակալ։

## English

Product-specific identity, workflows and components that are not part of the shared core (D-025 product boundary). Each extension has its own README, PROJECT_CONTEXT and ASSET_RECORDS.json and depends on [`../brand-expression/`](../brand-expression/).

- [`bro/`](bro/) — Bro, the MenQ AI agent.
