# Checkbox

**Status / Կարգավիճակ:** Draft (D-027, CR-0007)  
**Owner / Պատասխանատու:** MenQ Owner

## Հայերեն

Native checkbox՝ brand ոճով, 24px հպման տարածքով։

**Ինչ է տալիս օգտագործողը.** `label`, ըստ ցանկության `hint`, `invalid`, native checkbox-ի ատրիբուտներ։

**Կանոններ**
- Համաձայնության (consent) դաշտերի համար label-ը պետք է ամբողջական նախադասություն լինի։
- Focus-ը ցույց է տրվում `color-focus-ring`-ով։

## English

A native checkbox in the brand style, with a 24px hit area.

**The consumer provides:** `label`, optional `hint`, `invalid`, native checkbox attributes.

**Rules**
- For consent fields the label must be a complete sentence.
- Focus is shown with `color-focus-ring`.
