## English

Marketing section header: numbered index pill, eyebrow with a fading rule, display title and lead paragraph.

**The consumer provides:** `title`; optional `index`, `eyebrow`, `description`, `align`, `as`, `children`.

**Props**
- `align` — `center` · `left`
- `as` — `h2` (36px) · `h1` (48px)

**Rules**
- One `h1` per page.
- Description is `body-lg` in `color-content-secondary`, max `container-narrow`.
