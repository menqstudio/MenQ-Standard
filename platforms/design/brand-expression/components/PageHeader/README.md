## Հայերեն

**Ինչ է տալիս օգտագործողը.** `title`, ըստ ցանկության `subtitle`, `actions`։

**Props**
- `title`, `subtitle`, `actions`

**Կանոններ**
- Մեկ էկրանին մեկ հատ։ Վերնագիրը՝ `h3`, ենթավերնագիրը՝ `color-content-muted`։
