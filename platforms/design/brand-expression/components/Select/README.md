# Select

**Status / Կարգավիճակ:** Draft (D-027, CR-0007)  
**Owner / Պատասխանատու:** MenQ Owner

## Հայերեն

Native ընտրության ցանկ՝ `Input`-ի ոճով։

**Ինչ է տալիս օգտագործողը.** `option` տարրեր, native select-ի ատրիբուտներ, `invalid`։

**Կանոններ**
- Native `select`-ը պահպանում է ստեղնաշարի և screen reader-ի վարքագիծը. custom dropdown-ով չփոխարինել առանց պատճառի։

## English

A native select styled like `Input`.

**The consumer provides:** `option` children, native select attributes, `invalid`.

**Rules**
- The native `select` keeps keyboard and screen-reader behavior; do not replace it with a custom dropdown without a reason.
