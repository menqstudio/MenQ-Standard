## Հայերեն

Card՝ վերնագրով և գործողություններով։

**Ինչ է տալիս օգտագործողը.** `title`, ըստ ցանկության `actions`, `children`։

**Props**
- `title`, `actions`

**Կանոններ**
- Վերնագիրը `title` ոճով է, ներսի հեռավորությունը՝ `space-4`։

_Աղբյուր՝ BroPS src/components/ui.tsx։_
