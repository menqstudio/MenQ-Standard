## Հայերեն

Մուգ navy բաժին երկու թեմայում էլ։ tokens.css-ը նրա ներսում dark արժեքներ է տալիս։

**Ինչ է տալիս օգտագործողը.** `children`, ըստ ցանկության `spotlight`, `grid`, `labelledBy`։

**Props**
- `spotlight`, `grid`

**Կանոններ**
- Ներսում՝ `Card variant="premium"`։

_Աղբյուր՝ Webpage src/styles/tokens/sections.css։_

A dark navy section in both themes. tokens.css gives it the dark values.

**Rules**
