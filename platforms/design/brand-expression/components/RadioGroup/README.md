# RadioGroup

**Status / Կարգավիճակ:** Draft (D-027, CR-0007)  
**Owner / Պատասխանատու:** MenQ Owner

## Հայերեն

Ռադիո խումբ `fieldset` + `legend`-ով։

**Ինչ է տալիս օգտագործողը.** `label`, `options` (`value`, `label`, `hint`, `disabled`), `value`/`defaultValue`, `onChange`, `error`։

**Կանոններ**
- Սլաքներով տեղաշարժը native է։ 2–5 տարբերակի համար. ավելիի դեպքում՝ `Select`։

## English

A radio group with `fieldset` + `legend`.

**The consumer provides:** `label`, `options` (`value`, `label`, `hint`, `disabled`), `value`/`defaultValue`, `onChange`, `error`.

**Rules**
- Arrow-key movement is native. Use for 2–5 options; more than that, use `Select`.
