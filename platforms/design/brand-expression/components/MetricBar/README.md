**Status / Կարգավիճակ:** Draft (D-027)

## Հայերեն

Label-ով progress track՝ բրենդի գրադիենտով։

**Ինչ է տալիս օգտագործողը.** `label`, `value` (0–100), ըստ ցանկության `display`։

**Props**
- `value` — 0–100, սահմանափակված

**Կանոններ**
- Լցումը 700ms է, reduced motion-ի դեպքում՝ միանգամից։

_Աղբյուր՝ Webpage design-v2.css։_

## English

Labelled progress track with the brand gradient fill.

**Props**

**Rules**
- Fill animates over 700ms; instant under reduced motion.
