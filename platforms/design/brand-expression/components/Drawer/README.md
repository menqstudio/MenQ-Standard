# Drawer

**Status / Կարգավիճակ:** Draft (D-027)  
**Owner / Պատասխանատու:** MenQ Owner

## Հայերեն

Աջ կողմի պանել մանրամասների համար՝ առանց էկրանից դուրս գալու։

**Ինչ է տալիս օգտագործողը.** `title`, `onClose`, `children`, ըստ ցանկության `closeLabel`։

**Props**
- `title`, `onClose`, `inline`

**Կանոններ**
- Focus trap, Escape, `aria-modal`։ Լայնությունը՝ min(26rem, 94vw), z՝ `z-drawer`։

_Աղբյուր՝ MenQ addition։_

---

## English

Right context drawer for details without leaving the screen.

**The consumer provides:** `title`, `onClose`, `children`, optional `closeLabel`.

**Props**
- `title`, `onClose`, `inline`

**Rules**
- Focus trap, Escape, `aria-modal`. Width min(26rem, 94vw), z `z-drawer`.

_Source: MenQ addition._
