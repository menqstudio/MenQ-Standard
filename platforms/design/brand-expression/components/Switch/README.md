# Switch

**Status / Կարգավիճակ:** Draft (D-027, CR-0007)  
**Owner / Պատասխանատու:** MenQ Owner

## Հայերեն

Միացնել/անջատել կարգավորում՝ `role="switch"`։

**Ինչ է տալիս օգտագործողը.** `label`, `checked`/`defaultChecked`, `onChange`, `hint`, `disabled`։

**Կանոններ**
- Միայն անմիջապես կիրառվող կարգավորումների համար. ձևի մեջ, որը submit է արվում, օգտագործել `Checkbox`։

## English

An on/off setting with `role="switch"`.

**The consumer provides:** `label`, `checked`/`defaultChecked`, `onChange`, `hint`, `disabled`.

**Rules**
- Only for settings that apply immediately; inside a form that is submitted, use `Checkbox`.
