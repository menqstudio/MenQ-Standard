## Հայերեն

App icon-ների հավաքածու՝ պաշտոնական neon power-ring Q-ից, navy (`neutral-950`) ֆոնի վրա, որ փոքր չափերում և բաց/մուգ tab-երում հստակ երևա։

- `menq-icon.svg` — վեկտոր master (կլորացված քառակուսի)։ Ժամանակակից browser-ների favicon-ի համար (`<link rel="icon" type="image/svg+xml">`)։
- `favicon.ico` — 16, 32, 48 px՝ հին browser-ների համար։
- `apple-touch-icon.png` — 180×180, անթափանց (iOS-ը ինքն է կլորացնում)։
- `menq-icon-192.png`, `menq-icon-512.png` — PWA manifest-ի icon-ներ։
- `menq-icon-maskable.svg`, `menq-icon-maskable-512.png` — `purpose: "maskable"`, Q-ն 80% safe zone-ի ներսում։
- Չվերաներկել, Q-ն չձգել, ֆոնը չփոխել։ Նոր չափերը գեներացնել SVG master-ից։

## English

The app-icon set, made from the official neon power-ring Q on a navy (`neutral-950`) tile so it stays legible at small sizes and on light or dark tabs.

- `menq-icon.svg` — vector master (rounded tile). The favicon for modern browsers (`<link rel="icon" type="image/svg+xml">`).
- `favicon.ico` — 16, 32 and 48 px for older browsers.
- `apple-touch-icon.png` — 180×180, opaque (iOS rounds it).
- `menq-icon-192.png`, `menq-icon-512.png` — PWA manifest icons.
- `menq-icon-maskable.svg`, `menq-icon-maskable-512.png` — `purpose: "maskable"`, with the Q inside the 80% safe zone.
- Never recolour, stretch the Q or change the tile. Generate new sizes from the SVG master.
