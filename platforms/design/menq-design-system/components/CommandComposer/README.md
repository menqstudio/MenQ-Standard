# CommandComposer

Persistent Bro command input.

## The consumer provides
`onSubmit`, optional `placeholder`, `hint`, `sendLabel`, `label`.

## Props
- `onSubmit(text)`; Enter sends, Shift+Enter new line

## Rules
- Surface `glass surface`, focus ring `color-selected`. Prompt glyph in mono accent.

_Source: MenQ addition (standard: persistent Bro command access)._
