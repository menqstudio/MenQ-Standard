# ContrastSection

A dark navy section in BOTH themes. It re-declares the semantic color tokens locally, so every component inside renders correctly on dark.

## The consumer provides
`children`; optional `spotlight` (azure/cyan radial wash), `grid` (grid-line background), `labelledBy`.

## Rules
- Use once or twice per landing page for proof, results and AI sections.
- Inside, use `Card variant="premium"`.

_Source: Webpage src/styles/tokens/sections.css._
