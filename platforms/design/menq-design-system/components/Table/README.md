# Table

Data table with header, hover rows and cell renderers.

## The consumer provides
`columns` [{key,label,align?,render?}], `rows`, optional `caption`.

## Props
- `columns`, `rows`, `caption`

## Rules
- Header in `overline` style on `color-page-bg`. Numbers align right. Scrolls horizontally on narrow screens.

_Source: MenQ addition._
