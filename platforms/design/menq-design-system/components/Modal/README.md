# Modal

Dialog on a scrim. Escape and scrim click close it.

## The consumer provides
`title`, `onClose`, `children`; `inline` renders without the scrim (docs only).

## Props
- `title`, `onClose`, `inline`

## Rules
- `color-surface-elevated`, `radius-card`, `shadow-lg`, scrim `color-overlay`, z `z-modal`.

_Source: BroPS ui.tsx + Escape._
