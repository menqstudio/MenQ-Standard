# SectionHeading

Marketing section header: numbered index pill, uppercase eyebrow with a fading rule, display title, lead paragraph.

## The consumer provides
`title`; optional `index`, `eyebrow`, `description`, `align`, `as`, `children` (e.g. CTAs).

## Props
- `align`: `center` (default) · `left`
- `as`: `h2` (default, 36px) · `h1` (48px, page hero)

## Rules
- Title in `display`, tight leading 1.1, tracking −0.02em, balanced wrapping. Description `body-lg` in `color-content-secondary`, max `container-narrow`.
- One `h1` per page.
