# MetricBar

Labelled progress track with the brand gradient fill (the site's results bars).

## The consumer provides
`label`, `value` (0–100); optional `display` (text shown instead of the percent).

## Rules
- Track `color-surface-muted`, fill `gradient-brand`, `radius-pill`. Fill animates in over 700ms; instant under reduced motion.

_Source: Webpage design-v2.css (.metric-track/.metric-fill)._
