# ConfirmDialog

Second step before anything destructive.

## The consumer provides
`title`, `message`, labels, `onConfirm`, `onCancel`.

## Props
- `title`, `message`, `confirmLabel`, `cancelLabel`, `onConfirm`, `onCancel`

## Rules
- Ghost cancel left, danger confirm right. Never skip it for irreversible actions.
