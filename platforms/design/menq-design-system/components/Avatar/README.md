# Avatar

Initial badge for a human, Bro or a specialist agent.

## The consumer provides
`name`; optional `kind`.

## Props
- `kind`: (human) · `bro` · `agent`

## Rules
- Human: round, `color-selected`. Bro: solid `color-chat-bro-accent`. Agent: rounded square on `color-chat-agent-bg` — shape tells them apart, not colour alone.

_Source: BroPS ui.tsx + identity kinds._
