## Status / Կարգավիճակ

- **Languages:** Armenian + English

## Purpose / Նպատակ

**HY:** MenQ Standard-ը MenQ-ի ընդհանուր operating standard-ն է։ Այն միավորում է մտածողությունը, փաստաթղթավորումը, դիզայնը, ինժեներիան, AI համագործակցությունը, QA-ն, անվտանգությունը և պրոդուկտների կառուցման կանոնները։

**EN:** MenQ Standard is MenQ's shared operating standard. It unifies thinking, documentation, design, engineering, AI collaboration, QA, security, and product-building rules.

## Canonical rule / Canonical կանոն

**HY:** Չատերը ժամանակավոր են։ Հաստատված որոշումները պարտադիր տեղափոխվում են canonical փաստաթղթերի մեջ։

**EN:** Conversations are temporary. Approved decisions must be transferred into canonical documentation.
