## English
The Documentation chapter defines the canonical source, file roles, bilingual equality, metadata, change control, safe writes, and integrity verification. Every canonical write requires reading the complete source, preserving the SHA, re-reading the beginning and ending after the write, and declaring GREEN only after verification.
