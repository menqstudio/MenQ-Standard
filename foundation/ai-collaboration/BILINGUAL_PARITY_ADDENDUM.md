## Հայերեն

Այս հավելվածը չի փոխում AI Collaboration Standard v1-ի իմաստը։ Այն ամբողջացնում է legacy mixed-language sections-ի հայերեն canonical interpretation-ը՝ human purpose և final authority, AI-ի `G0–G2` սահման, explicit task contract, context precedence, memory isolation, truth/evidence distinction, tool և high-risk boundaries, agent delegation, failure handling և verified definition of done։

## English

This addendum does not change the meaning of AI Collaboration Standard v1. It completes the English canonical interpretation of legacy mixed-language sections: human purpose and final authority, AI limited to `G0–G2`, an explicit task contract, context precedence, memory isolation, truth/evidence distinctions, tool and high-risk boundaries, agent delegation, failure handling, and a verified definition of done.

## Precedence / Գերակայություն

This addendum supplies equal-language interpretation where legacy wording is mixed or incomplete without overriding a more specific bilingual rule in the parent standard.
