# MenQ Standard — Project Context

### Canonical source

MenQ Standard-ի միակ canonical repository-ն է՝

`https://github.com/menqstudio/MenQ-Standard`

AI օգնականը MenQ Standard-ի հետ կապված աշխատանք սկսելուց առաջ պարտադիր կարդում է repository-ի ընթացիկ վիճակը և առնվազն՝

1. `README.md`
2. `PROJECT_CONTEXT.md`
3. `DECISIONS.md`
4. `CHANGELOG.md`
5. համապատասխան թեմատիկ փաստաթուղթը

Repository-ի հասցեն, canonical source-ի ինքնությունը և արդեն փաստաթղթավորված մշտական կանոնները նոր chat-ում Owner-ից կրկին չեն հարցվում։ Repository-ն պետք է դիտարկվի որպես հիշողության և աշխատանքի շարունակականության հիմնական հիմք։

- Owner՝ Gevorg Ohanyan
